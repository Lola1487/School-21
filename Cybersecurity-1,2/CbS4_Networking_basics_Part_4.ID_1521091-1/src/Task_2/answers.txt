=============================================
Задание 2. Поиск следов обратной оболочки
=============================================

1. IP-адрес, с которого инициировался обратный шелл (жертва):
   192.168.1.101

2. IP-адрес, на который был проброшен обратный шелл (атакующий):
   192.168.1.100

3. Протокол, с помощью которого осуществлялся обратный шелл:
   TCP

4. Команды, переданные в рамках обратного шелла:
   - id
   - uname -a
   - whoami
   - ls -la /etc
   - cat /etc/passwd

=============================================
Ход анализа
=============================================

Для выявления обратного шелла в дампе some_troubled_traffic.pcapng
был выполнен следующий анализ:

1. Визуальный осмотр списка пакетов показал наличие HTTP, DNS, ICMP
   и множества TCP-соединений на нестандартные порты.

2. Применен фильтр tcp для выделения только TCP-трафика.

3. Обнаружено устойчивое взаимодействие между узлами 192.168.1.100
   и 192.168.1.101. Одна сторона отправляла команды, другая —
   результаты их выполнения.

4. При анализе TCP-потока (Follow → TCP Stream) выявлено, что
   команды передавались в открытом виде.

5. По характеру обмена определено, что 192.168.1.100 является
   атакующим (отправляет команды), а 192.168.1.101 — жертвой
   (выполняет команды и возвращает результат).

Признаки обратного шелла:
- Использование нестандартных портов
- Двусторонний интерактивный обмен данными
- Передача команд в текстовом виде
- Жертва инициирует подключение к атакующему
