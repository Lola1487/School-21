ОТЧЁТ ПО ЗАДАНИЮ 5: Уязвимость генерации nonce (ChaCha20)

Флаг:
S21{th1s_n0nc3_is_n0n_s3ns3_ch4_ch4_ch4}

Описание уязвимости:

В файле crypto_crack.py ошибка содержится в строке №12, а косвенно и в строке №9.

Строка 9: random.seed(int(time.time()))
Строка 12: nonce = struct.pack("<Q", random.randint(1, 2**64 - 1))

Почему это уязвимость:
- Модуль random в Python не является криптографически стойким. Он генерирует числа по детерминированному алгоритму.
- Функция seed() инициализирует генератор. Если известно значение seed, можно предсказать все последующие "случайные" числа.
- В качестве seed используется текущее время в секундах (int(time.time())). Это делает nonce предсказуемым.
- Nonce должен быть уникальным и непредсказуемым, особенно при использовании одного ключа для нескольких сообщений.

Метод взлома:

Поскольку seed — это количество секунд с 1 января 1970 года, общее количество возможных вариантов в пределах нескольких лет составляет не более 100-200 миллионов. Это число достаточно мало для перебора.

Алгоритм атаки:
1. Перебираются все возможные секунды в заданном диапазоне (например, за последние 3 года).
2. Для каждой секунды устанавливается seed: random.seed(секунда).
3. Генерируется nonce тем же способом, что и в исходной программе.
4. С известным ключом пытается расшифровать шифротекст.
5. Если расшифрованная строка начинается на "S21{" и заканчивается на "}", то nonce найден.

В результате перебора был получен флаг.

Как исправить уязвимость:

Вместо random и time.time() нужно использовать криптографически стойкий генератор случайных чисел:

from Crypto.Random import get_random_bytes
nonce = get_random_bytes(8)

Такой nonce будет действительно непредсказуемым.
