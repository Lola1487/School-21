ОТЧЁТ ПО ЗАДАНИЮ 4: Определение режимов шифрования

Содержимое файла operator.txt:

some_operating_mode_1.py: ECB
some_operating_mode_2.py: CBC
some_operating_mode_3.py: CFB
some_operating_mode_4.py: OFB
some_operating_mode_5.py: CTR

Признаки, по которым определён каждый режим:

1. ECB (Electronic Codebook)
   - Отсутствует вектор инициализации (IV).
   - Нет переменной, хранящей состояние между блоками.
   - Каждый блок шифруется независимо.
   - Одинаковые блоки открытого текста дают одинаковые блоки шифротекста.

2. CBC (Cipher Block Chaining)
   - Присутствует IV.
   - Перед шифрованием текущий блок открытого текста складывается по XOR с предыдущим блоком шифротекста (или IV для первого блока).
   - Формула: C_i = Encrypt(P_i XOR C_{i-1})
   - Ошибка при шифровании распространяется на все последующие блоки, при расшифровке — только на один байт следующего блока.

3. CFB (Cipher Feedback)
   - Присутствует IV.
   - Сначала шифруется предыдущий блок (или IV), затем результат складывается по XOR с текущим блоком открытого текста.
   - Формула: C_i = P_i XOR Encrypt(C_{i-1})
   - Обратная связь берётся из шифротекста.

4. OFB (Output Feedback)
   - Гамма генерируется независимо от данных: feedback = Encrypt(feedback) на каждом шаге.
   - Расшифровка полностью совпадает с шифрованием.
   - Ошибка в одном байте шифротекста влияет только на один байт открытого текста.

5. CTR (Counter Mode)
   - Вместо обратной связи используется счётчик, который увеличивается на каждом шаге.
   - Гамма = Encrypt(counter), затем counter++.
   - Расшифровка совпадает с шифрованием.
   - Позволяет параллельную обработку блоков и произвольный доступ к данным.
