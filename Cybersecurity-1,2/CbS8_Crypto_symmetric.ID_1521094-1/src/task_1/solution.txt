ОТЧЁТ ПО ЗАДАНИЮ 1: DES в режиме ECB

Флаг: S21{are_you_sure_about_this_algo?}

Описание решения:

В файле crypto_alphabet.py реализована функция super_encryption, которая шифрует каждый символ отдельно. Для одного символа сначала создаётся строка из 8 одинаковых символов (например, 'A' * 8 = 'AAAAAAAA'), а затем эта 8-байтовая строка шифруется с помощью DES в режиме ECB.

Особенности ECB:
- Одинаковые блоки открытого текста дают одинаковые блоки шифротекста.
- Нет вектора инициализации и нет связи между блоками.
- Это самый слабый режим, так как позволяет составить словарь соответствия блоков.

string.printable в Python содержит 100 символов в фиксированном порядке (digits, ascii_letters, punctuation, whitespace). Соответственно, ciphertext1 имеет длину 100 × 8 = 800 байт (1600 HEX-символов).

Первый шифротекст (ciphertext1) — это результат шифрования string.printable.
Второй шифротекст (ciphertext2) — это результат шифрования флага.

Алгоритм расшифровки:
1. Разбить ciphertext1 на блоки по 16 шестнадцатеричных символов (8 байт). Получилось 100 блоков.
2. Разбить ciphertext2 на блоки по 16 шестнадцатеричных символов.
3. С помощью binascii.unhexlify() преобразовать HEX-строки в байты.
4. Для каждого блока из ciphertext2 найти совпадающий блок в ciphertext1.
5. По позиции совпавшего блока определить символ из string.printable.
6. Собрать все символы в строку.

Почему ECB уязвим:
Так как одинаковые блоки шифруются одинаково, злоумышленник может составить таблицу соответствия между зашифрованными блоками и символами открытого текста (атака по словарю). В данном случае ключ DES не потребовалось подбирать — ECB позволил восстановить флаг простым сопоставлением блоков.
