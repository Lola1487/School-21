ЗАДАНИЕ 2. ПОТОКОВОЕ ШИФРОВАНИЕ

1. КАКОЙ АЛГОРИТМ ШИФРОВАНИЯ ИСПОЛЬЗОВАН?

Алгоритм называется RC4.

Коротко: это такой способ шифрования, когда каждый символ сообщения по очереди
складывается со случайным числом, которое получается из пароля.

2. КАКОЙ ПОЛУЧЕН ФЛАГ?

ФЛАГ:S21{my_f4v0rit3_c1ph3r_i5_RC4}

Это исходное сообщение, которое было зашифровано.

3. КАКИЕ ОШИБКИ БЫЛИ НАЙДЕНЫ В ИСХОДНОМ КОДЕ?
В файле crypto.py было найдено ДВЕ ошибки.

ОШИБКА №1 (строка 6)
Что написано в коде:
    j = (j + d[i] + b[i % c]) % 255

Как должно быть правильно:
    j = (j + d[i] + b[i % c]) % 256

Почему это ошибка простыми словами:
    В этом алгоритме используется таблица из 256 ячеек (номера от 0 до 255).
    Если использовать 255 вместо 256, то последняя ячейка (номер 255) никогда
    не будет использована. Это всё равно что испечь 256 пирожков, но съесть
    только 255. Это нарушает правильную работу шифра.

ОШИБКА №2 (строка 17)
Что написано в коде:
    k = c[(c[i] + c[i]) % 256]

Как должно быть правильно:
    k = c[(c[i] + c[j]) % 256]

Почему это ошибка простыми словами:
    В правильном алгоритме нужно складывать значения из двух разных ячеек
    (с номером i и с номером j). А в коде ошибочно сложили значение из ячейки i
    два раза (с самой собой). Это делает шифр слабым и неправильным.

4. КАК ПОЛУЧИЛИ ФЛАГ (ДЛЯ ТЕХ, КОМУ ИНТЕРЕСНО)
Процесс был такой:
    1. Взяли зашифрованное сообщение (оно дано в задании).
    2. Взяли пароль (он тоже дан в задании).
    3. Запустили алгоритм RC4 с этими данными.
    4. Алгоритм выдал результат: S21{my_f4v0rit3_c1ph3r_i5_RC4}

Проверка: Если взять этот флаг и зашифровать его с тем же паролем, то получится
тот самый шифротекст, который указан в задании. Значит, флаг верный.

    Ошибка 1: % 255 вместо % 256 (строка 6)
    Ошибка 2: c[i] + c[i] вместо c[i] + c[j] (строка 17)
