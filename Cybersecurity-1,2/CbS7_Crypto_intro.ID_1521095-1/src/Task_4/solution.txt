======================================================================

1. Суть алгоритма: В файле crypto.py используется шифрование на основе операции XOR (^).
Каждый символ исходного текста "складывается" по XOR с символом из ключа
'qwertyuioplkjhgfdsazlfmhkb'.

2. Главное свойство XOR: Эта операция обратима. Если A ^ B = C, то C ^ B = A.
Это значит, что один и тот же алгоритм можно использовать как для шифрования,
так и для расшифровки.

3. Ход решения: В условии задачи нам дана строка "\"4Rj\x12(\\_^(,{\x00c\r,OS]e$j\x18,Dl",
которая является РЕЗУЛЬТАТОМ работы функции encrypt_flag. Чтобы найти ИСХОДНЫЙ флаг,
нужно применить эту же самую функцию encrypt_flag к данному результату.

4. Проверка: Берём исходный код, подставим заданную зашифрованную строку в переменную
flag и запустим функцию encrypt_flag.
На выходе получилась читаемая строка S21{w45_17_cryp70_0r_wh47}, которая и является
искомым флагом.

5. Почему это работает: Алгоритм применяет XOR с тем же самым ключом.
 Первое применение XOR зашифровывает текст, второе применение XOR с тем же ключом отменяет
первое шифрование, возвращая исходный текст.
 Это похоже на то, как если бы мы включили и выключили свет —
 возвращаемся в исходное состояние.

 import base64

def encrypt(x, n):
    key = 'qwertyuioplkjhgfdsazlfmhkb'  # Фиксированный ключ для шифрования

    # Условие выхода из рекурсии: когда n равно длине строки x
    if n == len(x):
        return ''.join(x)  # Возвращаем строку, собранную из списка символов

    # Цикл для обработки символов от текущей позиции n до конца строки
    for i in range(n, len(x)):
        # ОСНОВНАЯ ОПЕРАЦИЯ: XOR (^) между кодом символа строки и кодом символа ключа
        # key[i - n] обеспечивает сдвиг начала ключа для каждого "слоя" рекурсии
        x[i] = chr(ord(x[i]) ^ ord(key[i - n]))

    # Рекурсивный вызов с увеличенным n (переход к следующему "слою")
    return encrypt(x, n + 1)

def encrypt_flag(flag):
    # Преобразуем строку флага в список символов и начинаем шифрование с n=0
    return encrypt(list(flag), 0)
