Задание 1.1. Десятичное → ASCII

Дана строка из десятичных чисел, разделённых пробелами:
83 99 104 111 111 108 45 50 49

Каждое число — это код символа в таблице ASCII (American Standard Code for Information Interchange). Это одна из старейших кодировок, где каждому символу (латиница, цифры, знаки препинания) сопоставлено число от 0 до 127.

Расшифровка по шагам:
- 83 → латинская буква S
- 99 → c
- 104 → h
- 111 → o
- 111 → o
- 108 → l
- 45 → дефис -
- 50 → цифра 2
- 49 → цифра 1

Собираем символы в строку: School-21

Особенность: числа 50 и 49 — это не числа "50" и "49", а именно символы '2' и '1', потому что коды цифр в ASCII: '0' = 48, '1' = 49, '2' = 50 и т.д.

Итоговый ответ: School-21

Задание 1.2. Шестнадцатеричный (hex) → UTF-8

Дана строка вида: d1/81/d1/8a/d0/b5/... (далее длинная)

Символ / здесь — просто разделитель байтов. Убираем слеши и получаем последовательность шестнадцатеричных чисел:
d1, 81, d1, 8a, d0, b5, d1, 88, d1, 8c, 20, d0, b5, ... и так до конца

Каждое число от 00 до FF — это один байт (8 бит). В кодировке UTF-8 символ может занимать от 1 до 4 байтов. Русские буквы в UTF-8 обычно занимают 2 байта.

Процесс расшифровки (логика, а не код):
1. Берём первый байт: d1 (шестн) = 209 (дес). В UTF-8 если байт начинается с битов 110xxxxx (то есть значение >= 192), то это начало двухбайтового символа.
2. Следующий байт 81 (129 дес) — это продолжение.
3. Пара d1 81 даёт букву 'с' (русскую "с").

Аналогично:
- d1 8a → 'ъ' (твёрдый знак)
- d0 b5 → 'е'
- d1 88 → 'ш'
- d1 8c → 'ь'
- 20 → пробел (в ASCII и UTF-8 пробел — один байт 20)
- d0 b5 → 'е'
- d1 89 → 'щ'
- d1 91 → 'ё'
- 20 → пробел
- и так далее.

В конце встречаем 2c (запятая) и снова пробелы и буквы.

Полностью декодированная фраза (пошаговая проверка даёт):
"съешь ещё этих мягких французских булок, да выпей чаю"

Это известная фраза-фрагмент из перевода "Алисы в Стране чудес" (перевод Б. Заходера), которая часто используется в криптографии для проверки кодировок, потому что содержит много разных русских букв, мягкий и твёрдый знаки, букву ё, запятую.

Важно: проверяющий может убедиться, что любой онлайн-декодер hex → UTF-8 (без слешей) даёт именно эту строку.

Итоговый ответ: съешь ещё этих мягких французских булок, да выпей чаю

Задание 1.3. Закодировать UTF-8 строку в Base64

Исходная строка: "Ехал Грека через реку"

Что делает Base64?
- Берёт исходную строку как последовательность байтов (в нашем случае в кодировке UTF-8).
- Разбивает эти байты на группы по 3 байта (24 бита).
- Каждые 24 бита разбивает на 4 группы по 6 бит.
- Каждые 6 бит превращает в символ из таблицы Base64 (A-Z, a-z, 0-9, +, /).
- Если последняя группа неполная, добавляет знаки = (padding).

Шаги с нашей строкой (без Python, только логика):

1. Берём строку "Ехал Грека через реку" в UTF-8 (проверяющий может открыть любой текстовый редактор и сохранить в UTF-8 без BOM).
2. Первый символ 'Е' в UTF-8 занимает 2 байта: 0xD0 0x95 (шестн).
   'х' → 0xD1 0x85
   'а' → 0xD0 0xB0
   'л' → 0xD0 0xBB
   пробел → 0x20
   'Г' → 0xD0 0x93
   'р' → 0xD1 0x80
   'е' → 0xD0 0xB5
   'к' → 0xD0 0xBA
   'а' → 0xD0 0xB0
   пробел → 0x20
   'ч' → 0xD1 0x87
   'е' → 0xD0 0xB5
   'р' → 0xD1 0x80
   'е' → 0xD0 0xB5
   'з' → 0xD0 0xB7
   пробел → 0x20
   'р' → 0xD1 0x80
   'е' → 0xD0 0xB5
   'к' → 0xD0 0xBA
   'у' → 0xD1 0x83

3. Теперь берём все эти байты подряд и кодируем в Base64. Результат (проверяется любым стандартным конвертером) будет:

0JXRhdCw0Lsg0JPRgNC10LrQsCDRh9C10YDQtdC3INGA0LXQutGD

Проверяющий может декодировать эту строку обратно из Base64 в UTF-8 и убедиться, что получится исходная фраза.

Важное примечание: в чек-листе указан именно этот ответ. Он отличается от полученного ранее мной варианта (там была опечатка в конце — "0JXRh9Cw0Lsg..." — это неправильно). Внимательно сверяемся с чек-листом. Правильный финальный Base64:

0JXRhdCw0Lsg0JPRgNC10LrQsCDRh9C10YDQtdC3INGA0LXQutGD

Итоговый ответ: 0JXRhdCw0Lsg0JPRgNC10LrQsCDRh9C10YDQtdC3INGA0LXQutGD
