2-3. Представь, что тебе нужно выделить подсети для различных сегментов организации N — технологического (3 машины),
     серверного (16 машин) и пользовательского (32 машины). Сети с какими масками необходимо выделить для каждого из сегментов? Приведи обоснование своего ответа.


   2-3.1.   Технологический сегмент (3 машины):

            Подсеть должна обеспечивать минимум 3 адреса для устройств, но также требует адрес для сети и адрес для широковещательной рассылки.
            Минимальное количество адресов, необходимое для 3 устройств, составляет 5 (3 устройства + 1 адрес сети + 1 широковещательный адрес).

            Наилучшим выбором будет маска /29 (11111111.11111111.11111111.11111000), которая даст 8 адресов (2^3).

            Пример выделения подсети: 192.168.1.0/29.

   2-3.2.   Серверный сегмент (16 машин):

            Для серверного сегмента нам нужно 16 адресов для машин, а также 1 адрес для сети и 1 адрес для широковещательной рассылки => минимум 18 адресов.

            Для этого подойдет маска /27 (11111111.11111111.11111111.11100000), которая даст 32 адреса(2^5).

            Пример выделения подсети: 192.168.1.8/27.

   2-3.3.   Пользовательский сегмент (32 машины):

            Для обеспечения адресности нужно 32 адреса для устройств, плюс 1 адрес для сети и 1 для широковещательной рассылки => минимум 34 адреса.

            Подходит маска /26 (11111111.11111111.11111111.11000000), которая дает 64 адреса (2^6).

            Пример выделения подсети: 192.168.1.41/26.
