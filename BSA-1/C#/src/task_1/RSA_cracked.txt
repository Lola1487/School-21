2. КАК РАБОТАЕТ RSA

RSA — это алгоритм шифрования:

- Есть два ключа: открытый (n, e) и закрытый (d, n).
- Открытый ключ можно передавать по сети.
- Закрытый ключ знает только владелец.

Шифрование:
   c = m^e mod n
   где m — исходное сообщение (число), c — шифротекст.

Расшифрование:
   m = c^d mod n

Обычно расшифровать без закрытого ключа d — очень сложно (нужно разложить n на множители).

3. ПОЧЕМУ ЭТО ЗАДАНИЕ УДАЛОСЬ РЕШИТЬ

  КЛЮЧЕВОЙ МОМЕНТ:
  Экспонента ФЛАГ:e = 5 — ОЧЕНЬ МАЛЕНЬКАЯ.
  Модуль n — ОЧЕНЬ БОЛЬШОЙ.

Если исходное сообщение m не очень большое, то m^5 может быть МЕНЬШЕ, чем n.

А если m^5 < n, то:
   c = m^5   (потому что "mod n" ничего не меняет — число и так меньше n)

Тогда:
   m = корень 5-й степени из c

И для расшифровки НЕ НУЖЕН секретный ключ d!

4. ПРОВЕРКА, ЧТО УСЛОВИЕ ВЫПОЛНИЛОСЬ

Мы вычислили m = целочисленный корень 5-й степени из c.
Затем проверили: m^5 == c ?

✅ ДА, равенство выполняется.
Значит, m^5 действительно меньше n, и наша атака сработала.

6. КАК ЭТО БЫЛО СДЕЛАНО (ДЛЯ ТЕХНИЧЕСКИ ПОДКОВАННЫХ)

Метод: атака на RSA с маленькой открытой экспонентой.

Алгоритм:
1. Взять шифротекст c.
2. Вычислить целочисленный корень 5-й степени методом бинарного поиска.
3. Проверить, что (корень)^5 == c.
4. Преобразовать полученное число в байты (big-endian).
5. Декодировать в UTF-8.

Код на Python (упрощённо):

c = int(c_hex, 16)
e = 5

def integer_nth_root(x, n):
    # бинарный поиск корня
    low, high = 1, 1
    while high ** n <= x:
        high *= 2
    while low < high:
        mid = (low + high + 1) // 2
        if mid ** n <= x:
            low = mid
        else:
            high = mid - 1
    return low

m = integer_nth_root(c, e)
flag = m.to_bytes((m.bit_length() + 7) // 8, 'big').decode('utf-8')
print(flag)
